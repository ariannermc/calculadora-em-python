# 🔢 Calculadora Python
>Calculadora de terminal com menu interativo e histórico de operações, desenvolvida em Python puro.

---

## 💻 Demo
```
====CALCULADORA====
1- somar
2- subtrair
3- multiplicar
4- dividir
5- sair
6- histórico
===================
escolha: 1
primeiro numero: 10
segundo numero: 5
10.0 + 5.0 = 15.0
```

---

## 💡 Funcionalidades
- ➕ Adição
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão
- 📝 Histórico de todas as operações realizadas
- 🔁 Loop contínuo  -- a calculadora fica aberta até escolher sair no menu

---

## 🚀 Como usar

**Pré-requisitos:** Python 3 deve estar instalado. </br>
Verifique com:
```
python --version
```

**Passos:**
1. Clone o repositório:
```
git clone https://github.com/ariannermc/calculadora-em-python.git
cd calculadora-em-python
```
 
2. Execute o script:
```
python calculadora.py
```
 
3. Escolha uma opção do menu e insira os números quando solicitado.
